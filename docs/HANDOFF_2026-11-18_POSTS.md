## Главное уточнение пользователя об операторе

На один пост пользователь закладывает несколько видов работ, например резку листа 10 мм, резку профиля и резку листа 5 мм. Сумма погонных метров этих позиций должна участвовать в расчёте нормо-часов оператора поста.

```text
Lпоста = Lрезки10мм + Lрезкипрофиля + Lрезки5мм + ...
Hоператора = Lпоста / Pоператора
Cоператора = Hоператора × Rоператора
```

Здесь Pоператора — согласованная выработка оператора в п.м./н·ч, Rоператора — ставка в ₽/н·ч.

Каждая позиция резки сохраняет свою длину, материал, толщину и тариф. Оператор — одна общая статья затрат поста, зависящая от нескольких работ. Добавление, удаление и изменение участвующих работ должны пересчитывать общий объём и часы оператора.

В сумму метрики не добавлять длины из строк подготовки чертежей, разработки УП и самого оператора. Считать объёмы применяемого маршрута; взаимоисключающие варианты одного и того же реза не должны давать повторную длину. Все объёмы перед суммированием должны иметь совместимые единицы и одну базу учёта. Тираж учитывать один раз.

Состав источников зависимости должен быть явным. Пользователю предложено обозначать общий цех и пост, этапы и метрику, а в Q оператора записывать правило суммирования; для ограниченного набора работ — перечислять ID из A. Это способ согласования в XLSX, а не уже реализованная функция приложения.

## Значение столбца M

M «Учёт в сумме поста» определяет включение денежных затрат. Это не переключатель зависимости физических метрик.

| Значение | Смысл |
| --- | --- |
| Отдельно | Самостоятельная денежная затрата, включается в итог выбранного маршрута |
| Включено в другую строку | Уже оплачено в другом тарифе; повторно не прибавлять, указать ID содержащей строки в Q |
| Альтернатива | Другой способ расчёта того же объёма; сначала выбрать применяемый вариант |
| Не применяется | Работа не требуется для маршрута |
| Не определено | Включение затрат ещё не согласовано |

Для обсуждаемой схемы отдельной оплаты оператору и всем выбранным позициям резки ставится «Отдельно». Зависимость часов оператора от метров резки сама по себе не является двойным денежным учётом.

Условие: ставки резки не должны уже содержать оплату этого оператора. Если содержат, оператору ставится «Включено в другую строку» либо его труд сначала явно выделяется из тарифов резки. Состав ставок в этом чате не был подтверждён.

Пользователю также объяснено различие между включением и альтернативой: расчёт одной резки по метрам и расчёт той же резки по часам не нужно суммировать как две самостоятельные обработки.

## Как читать поля XLSX

На листе «Согласование» заголовки в строке 10, данные в строках 11–200.

| Столбец | Назначение |
| --- | --- |
| A | Стабильный ID работы; при сверке ориентироваться на него, а не номер строки Excel |
| B | Название работы |
| C | Исходный текущий цех |
| D | Цех для согласования, редактируется пользователем |
| E | Код поста |
| F | Название поста, формула по коду E и листу «Посты» |
| G | Этап, например «Основная операция», «Управляющая программа», «Оператор» |
| H и I | Метрика и её единица |
| J | Способ расчёта |
| K | База объёма: партия, изделие, уникальная УП и др. |
| L | Правило повторения |
| M | Включение денежных затрат |
| N и O | Новая выработка пользователя и её единица; пустота не означает ноль |
| P | Решение по строке: «Не проверено», «Согласовано», «Изменить», «Исключить» |
| Q | Комментарий пользователя, включая зависимости и ID источников |
| R–V | Ставка, единица, выработка и технический статус нормы из источника |
| W | Текстовое выражение расчёта, не числовая калькуляция заказа |
| X | Исходный вопрос для согласования |
| Y | Книга, лист и ячейка цены |
| Z | Проверка наличия кода поста |

Для оператора по сумме метров предложено: G «Оператор», H «Сумма длин реза работ поста», I «м.п.», J «По выработке», K — согласованная база исходных объёмов, N/O — согласованная выработка в м.п. за н/ч. Это предложение не применять вслепую к строке 103 с драйвером по листам.

Пользователю даны инструкции по условному форматированию: для диапазона P11:P200 правило `=$P11="Согласовано"` с зелёной заливкой и `=$P11="Исключить"` с красной. Для окраски целых строк область A11:Z200, формулы те же. По запросам с этими инструкциями агент файл не изменял.

## Подтверждённые ограничения

1. `Number(null)` в `normHours` даёт 0. Строка с разрешённой нормой, пустым физическим объёмом и совпадающими единицами получает 0 часов и 0 стоимости. Ошибка воспроизведена в этом чате, не исправлена.
2. В этом же ядре `м` и `м.п.` не нормализуются: сравнение единиц строковое.
3. Сумма всех рёбер модели не равна длине контуров реза. Площадь закупленного листа не заменяет эту длину.
4. Шаблоны XLSX не являются готовым импортом или работающим механизмом исключения денежных дублей.
5. База подготовки УП / чертежей и база тиражной обработки согласуются отдельно. Первоначальная идея уникальной УП не должна перезаписывать более поздний выбор пользователя «На партию» в конкретной строке.
