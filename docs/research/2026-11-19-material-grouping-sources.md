# Группировка материалов: проверенные внешние основания

Дата проверки: 19.11.2026. Область: модель категорий и доступное сворачивание табличных разделов локального JS-калькулятора. Это исследование; код и база не изменялись.

## Проверенные факты

1. **Категория и характеристика решают разные задачи.** В официальной документации Odoo категории магазина объединяют товары для навигации; атрибут описывает характеристику товара, например цвет или материал, и имеет значения. Вариант товара — комбинация атрибутов, которая может отличаться ценой или доступностью. Отдельная «категория атрибутов» группирует сами характеристики при сравнении, а не товары. Источник: [Odoo, Categories and variants, saas-19.1](https://www.odoo.com/documentation/saas-19.1/applications/websites/ecommerce/configuration/categories_variants.html).

2. **Для сворачивания достаточно disclosure.** W3C APG определяет кнопку и управляемый ею раздел содержимого. Enter и Space переключают видимость; `aria-expanded` на кнопке отражает состояние (`true` / `false`). `aria-controls`, указывающий ID управляемого контейнера, необязателен. Источник: [W3C WAI APG, Disclosure Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/).

3. **Таблица может содержать обычные элементы управления.** APG рекомендует нативный HTML `table`, когда он подходит. Кнопки и поля внутри таблицы остаются отдельными остановками Tab; сама таблица не приобретает клавиатурную модель `grid`. Для скрытых/отсутствующих строк APG отдельно рассматривает общее количество и индексы строк. Источник: [W3C WAI APG, Table Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/table/).

## Рекомендации для калькулятора — выводы, а не требования источников

- Раздел материала отвечает на вопрос «что это»: например, листовые материалы или крепёж. Толщина, цвет, марка, размер и поставщик остаются отдельными характеристиками, если они уже представлены в базе. Не создавать раздел под каждую комбинацию свойств.
- Для первого варианта достаточно одной основной группы на запись и группы «Без группы» для старых или неразобранных записей. Это локальное упрощение: Odoo допускает несколько магазинных категорий у товара; копировать такую множественность здесь необязательно. [Основание для разграничения](https://www.odoo.com/documentation/saas-19.1/applications/websites/ecommerce/configuration/categories_variants.html).
- Название группы сделать доступной нативной кнопкой со счётчиком записей. Состояние `aria-expanded` синхронизировать с фактической видимостью. Табличные заголовки и элементы редактирования сохранить. [Основание для управления](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/).
- Если существующая общая таблица не нужна для выравнивания и сортировки всех строк, отдельная нативная таблица внутри каждого скрываемого раздела проще для семантики. Если нужна одна общая таблица, способ группировки её строк необходимо проверить отдельно; нельзя помещать произвольные контейнеры между табличными элементами. Это инженерный выбор, APG не даёт готового рецепта именно для этой базы. [Основание для сохранения таблицы](https://www.w3.org/WAI/ARIA/apg/patterns/table/).

## Практические ограничения

- Источники не определяют конкретный список групп для этой базы: его нужно сверить с фактическими материалами. Классификация по словам в названии годится лишь для предварительного предложения с ручной проверкой.
- Сворачивание должно менять представление, а не удалять записи и не исключать их из расчётов. Поиск должен позволять обнаружить совпадения в закрытых разделах. Это рекомендации для поведения калькулятора, не утверждения о реализации Odoo.
- APG описывает семантику и взаимодействие, но не доказывает доступность конкретной реализации. При реализации нужны проверки Tab, Enter, Space, фокуса при закрытии и чтения таблицы вспомогательными технологиями.
- Переход на ERP и новые зависимости не требуются. Реализация, миграция данных и браузерные проверки в это исследование не входили.

Примечание к проверке Odoo: прямое открытие страницы дало тайм-аут; определения и разделы Attributes / Shop categories проверены в доступном поисковом представлении страницы официального домена. Документация описывает версию saas-19.1, а не текущую схему калькулятора.
