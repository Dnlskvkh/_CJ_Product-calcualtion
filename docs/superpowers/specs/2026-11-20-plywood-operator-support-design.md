# Автоматическое сопровождение фрезерного раскроя

Задача пользователя: при добавлении раскроя автоматически добавлять сопровождение, рассчитывая человеко-часы из метража и толщины фанеры.

Используются существующие операции поста P07 и Р103.P07. Часы сопровождения = сумма машино-часов выбранных раскроев × 30/60. Пример: 135 м фанеры 6 мм / 135 + 45 м фанеры 18 мм / 45 = 2 маш·ч = 1 чел·ч. Нормы берутся из сохранённого определения каждой операции.

При сохранении рабочего расчёта добавляется одна обычная строка сопровождения на изделие / пакет / участок. Существующее сопровождение, ставки и ручные часы не заменяются. Автоматическая строка получает production.autoSupport и удаляется вместе с последним раскроем своего участка. Исключённые раскрои дают ноль часов; УП и чертежи не создают сопровождение.

Включение труда в ставку раскроя противоречит запросу на отдельную строку. Добавление при просмотре незаметно меняло бы сохранённые расчёты. Поэтому выбран существующий путь явного сохранения. Другие посты, архивы и установленная копия автоматически не меняются.

Проверки: автодобавление, толщина, метры, тираж, исключение и удаление, ручное сопровождение, разные участки, JSON и ошибка записи; общий набор и сборка.

Уточнение пользователя: в строке сопровождения редактируются только чел·ч, себестоимость часа показывается без редактирования. inputs.person_hours задаёт ручные часы, включая 0; очистка возвращает прежний автоматический расчёт. В карточке доступно то же поле. Явные ручные часы имеют приоритет над нормой и интервалами, сами интервалы сохраняются.
