# Material Grouping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Сгруппировать материалы текущей калькуляции по согласованным разделам и типам.
**Architecture:** Чистый модуль классификации и группировки рассчитанных строк. Существующая таблица закупки и редактор используют его; расчётные ядра не меняются.
**Tech Stack:** Vanilla JavaScript, CommonJS checks, существующий Worker/PWA/SQLite.
**Spec:** ../specs/2026-11-19-material-grouping-design.md

## Global Constraints

- Сохранить ставки, единицы, объёмы, запасы, кратность, граф, версии и клиентский whitelist.
- `group` не использовать для классификации. `materialType` необязателен; ручной выбор имеет приоритет.
- Неизвестная сумма отличается от нуля. Каждая строка показывается один раз.
- Без новых зависимостей/SQL-таблиц/изменения поиска.

## Review Focus

- Ошибочные категории «Работы», смешанные HDPE, ручные трубы и переименованные позиции.
- Частично известная сумма и явный ноль; смешанные единицы не складываются.
- Сворачивание не меняет данные/фокус/соседние разделы, сбой настройки не скрывает строки.
- Подделанный тип из импорта отклоняется, выбор сохраняется в JSON/копии и не попадает в клиентское КП.
- Настоящая таблица review-ui заменяет исходную таблицу app.js; проверить итоговый DOM и узкий экран.
