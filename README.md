# _CJ_Product-calcualtion

Калькулятор себестоимости и цены изделий: материалы, производственные операции, версии расчётов и коммерческие предложения. Поддерживает PWA и переносной запуск на Windows x64.

## Запуск исходников

Требуется Node.js с поддержкой `node:sqlite`. Команды выполняются из `source-project`:

```powershell
corepack pnpm install --frozen-lockfile
node build-worker.cjs
node run-checks.cjs
node preview-server.cjs
```

Предпросмотр: http://127.0.0.1:4188 с временной базой в памяти. Переносная сборка: `node build-portable.cjs`; готовый ZIP содержит Node.js и запускается через «Запустить калькулятор.cmd» на Windows 10/11 x64.

## Последняя версия

Сборка от 20 ноября 2026 года (Asia/Vladivostok) включает автоматическое сопровождение станочных операций и уточнённую норму раскроя фанеры. Сведения о проверенной сборке и SHA-256 находятся в [манифесте](docs/releases/2026-11-20.json). Готовые ZIP размещаются в GitHub Releases.

Рабочие исходники интерфейса находятся в `source-project/dist/`; этот каталог необходим для сборки. Подробности: [README](source-project/README.txt), [архитектура](source-project/ARCHITECTURE.txt), [требования к автоматизации труда](docs/OPERATION_AUTOMATION_REQUIREMENTS.md).

Исходные справочники содержат внутренние цены и нормы, поэтому репозиторий предназначен для закрытого доступа. Пользовательские базы, резервные копии, старые сборки, снимки экранов и секреты не включены. Сохранённые заказы переносятся отдельно через резервные копии приложения.
