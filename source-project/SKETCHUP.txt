КАЛЬКУЛЯТОР В SKETCHUP · 0.2.0 · ЛОКАЛЬНО

Для SketchUp Desktop 2024–2026 на Windows. Установочный пакет RBZ содержит
текущий калькулятор, справочники и шрифты; Node.js на рабочем месте не нужен.
Пакет не подписан для Extension Warehouse. SketchUp Web не поддерживается.

УСТАНОВКА
1. Window / Окно → Extension Manager / Диспетчер расширений → Install Extension.
2. Выберите CJ-Calculator-SketchUp-0.2.0-<дата>.rbz из outputs/sketchup.
3. После установки перезапустите SketchUp, затем откройте
   Extensions / Расширения → CJ · Калькулятор изделий.
   Для выделения также есть пункт контекстного меню.

РАБОТА С ДЕТАЛЯМИ
1. Сохраните SKP перед первым импортом, затем выделите нужные группы,
   компоненты, грани или рёбра в самой модели.
2. В калькуляторе нажмите «Выбрать геометрию для расчёта» → «Получить выделение».
3. По умолчанию вложенные узлы без собственной геометрии раскладываются
   на отдельные детали. Смешанный узел остаётся целиком. Родитель и его
   дочерние детали одновременно не начисляются. Каждый экземпляр отдельно.
4. Скрытые объекты и выключенные теги по умолчанию исключаются.
   Сечения, настройки камеры и отсечение по экрану не задают границы выборки.
5. Проверьте габариты X/Y/Z, площадь всех граней, объём и сумму рёбер.
   Отметьте нужные строки и выберите величину для расхода или оставьте выбор
   в помощнике. Затем нажмите «Проверить и подобрать позиции».
6. Помощник позволяет выбрать материал/работу из справочника, единицы,
   подтверждённую норму и основание. Новая своя позиция имеет неизвестную цену.
   Расчёт изменяется только по кнопке «Добавить выбранное» с восстановительной
   копией, как при обычном импорте спецификации.

ПОДБОР МАТЕРИАЛА ПО НАЗВАНИЯМ
Панель автоматически читает имя экземпляра, имя определения компонента,
тег (слой), материал оформления и подходящие теги родительских узлов.
Собственные признаки детали имеют приоритет перед тегом родителя.
Показываются предполагаемый материал, исходные названия и до 8 ближайших
вариантов актуального справочника. Точное единственное название предложено
в списке сразу; похожие названия требуют выбора. Противоречивые собственные
названия не разрешаются молча. Архивные позиции и позиции для сверки исключены.
Распознаются русские и распространённые английские названия, различаются
породы дерева, явно названные марки AISI/09Г2С/Ст3 и указанные толщины листов.
Это текстовые подсказки, а не подтверждение состава материала. Если нужного
названия нет, уточните поиск или оставьте свою позицию с неизвестной ценой.
Выбранная позиция передаётся в помощник с её настоящей единицей ставки.
Площадь в м² не становится количеством листов, объём в м³ — килограммами:
при разных единицах нужны явная норма и основание. Выбор материала можно
снять; автоматическая подсказка не восстанавливает снятый выбор.
Подбор отмечен как предположение, исходные названия сохраняются в происхождении
расчётной строки и спецификации. Новые ставки/плотности не придумываются;
существующие расчёты, версии и КП автоматически не меняются.

ЧТО ОЗНАЧАЮТ ИЗМЕРЕНИЯ
— Все числа пересчитаны из внутренних дюймов SketchUp в м, м² и м³,
  независимо от точности и единиц отображения модели.
— Габариты измеряются вдоль локальных осей группы/компонента с учётом
  масштаба, вращения, отражения и преобразований родительских узлов.
  Габарит не является длиной заготовки или развёрткой криволинейной детали.
— Поверхность — сумма площадей граней с одной стороны каждой грани.
  Соприкасающиеся, внутренние грани и технологические припуски не исключаются.
  Площадь окраски и число слоёв нужно назначать явно.
— Объём есть только у отдельной замкнутой группы/компонента без вложенных
  экземпляров и исключённой скрытой геометрии. В остальных случаях null,
  а не ноль. Сумма объёмов пересекающихся тел не выдаётся за объём объединения.
— Все рёбра — геометрическая сумма, включая внутренние линии сетки.
  Это не периметр раскроя и не длина сварки. Выбор этой величины явный.
— Для прямой выбранной грани доступна площадь грани; для группы такая
  величина неизвестна. Масса без подтверждённой плотности не вычисляется.
— Материал SketchUp — только подпись оформления, без определения марки,
  закупочной цены, плотности или технологии.
— Выделение считается составом одного изделия; если выделена вся партия,
  скорректируйте границы и область учёта в помощнике. Тираж не угадывается.

ДАННЫЕ И ОБНОВЛЕНИЯ
Работает локальная база CEF SketchUp. Она отделена от базы сайта и браузера.
Для переноса используйте «Сервер и копии» → полную копию базы, для рабочего
расчёта — JSON. Не очищайте профиль CEF и не переустанавливайте расширение
без копий. Автоматическая синхронизация с опубликованным сайтом не включена.
Модель не изменяется; в SKP не записываются расчёты и цены. Окно привязано
к модели при открытии; после переключения модели закройте и откройте его снова.
Измерения — снимки по явному запросу. Изменение модели не обновляет ставки,
версии, КП и уже добавленные строки. Неизменённый повторный импорт блокируется
существующим помощником. Изменённую геометрию проверяйте в отдельном расчёте:
сопоставление и замена ранее импортированных строк пока не реализованы.
Идентификатор сохранённой модели строится из хеша пути файла; обычное
сохранение SKP его не меняет. Для несохранённой модели используется GUID.
Перенос/переименование файла или первое сохранение прежде несохранённой
модели меняют источник: не импортируйте такой файл повторно в прежний расчёт.

ЭКСПОРТ И PDF
JSON, CSV, XLSX и HTML сохраняются через обычное окно Windows.
Для PDF сохраняется HTML с документом: откройте его в Chrome/Edge и выберите
«Печать → Сохранить как PDF». Внутренний отчёт содержит встроенные шрифты.
Для клиента используйте только клиентский документ/КП, не внутренний отчёт.

СБОРКА И ПРОВЕРКИ
node sketchup-check.cjs — обмен и измерения → существующий помощник.
node run-checks.cjs — общие проверки калькулятора, включая обмен SketchUp.
node build-sketchup.cjs — сборка Worker/PWA, проверки обмена и RBZ.
node sketchup-package-check.cjs — ресурсы и содержимое последнего RBZ.
sketchup/geometry-check.rb — проверки в Ruby SketchUp без изменения модели.
sketchup/ui-check.js — тест встроенного окна с синтетическими данными,
  отдельным callback cj_probe и подменой сохранения; не обычный скрипт приложения.
Фактическая проверка и её границы: SKETCHUP_VALIDATION.txt.
Исходники расширения: sketchup/; сборка: outputs/sketchup/.
site-edit, опубликованный сайт и рабочая удалённая база не меняются.
