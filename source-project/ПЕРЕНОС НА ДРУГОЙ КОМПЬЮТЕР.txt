ПЕРЕНОС КАЛЬКУЛЯТОРА НА ДРУГОЙ КОМПЬЮТЕР
Снимок папки проекта от 22.10.2026.

1. Распакуйте ZIP целиком в обычную папку. Не запускайте файлы внутри ZIP.
2. Для запуска модульной версии установите Node.js с поддержкой node:sqlite
   (на исходном компьютере использован Node.js 24.19.0).
3. Дважды щёлкните «Запустить калькулятор.cmd» в корне распакованной папки.
4. Откройте в Chrome или Edge: http://127.0.0.1:4173
   Окно запуска оставляйте открытым. Для остановки закройте его.
   Этот запуск обслуживает корневой dist и не поднимает серверную базу.
5. Отдельный автономный HTML находится в корне:
   «Калькулятор — внутренний отчёт.html». Его можно открыть браузером без Node.js.

ПЕРЕНОС ПОЛЬЗОВАТЕЛЬСКИХ ДАННЫХ
Файлы проекта не содержат localStorage браузера и базу опубликованного сайта.
На старом компьютере сохраните резервную копию через «Сервер и копии»
и отдельно сохраните нужные рабочие калькуляции в JSON.
На новом компьютере используйте соответствующие команды восстановления/открытия.
Данные разных браузеров и адресов сайта хранятся раздельно.
Перед восстановлением сделайте копию имеющихся данных на новом компьютере.
Серверная синхронизация требует опубликованного сайта и доступа к нему.
preview-server.cjs использует временную БД: она исчезает при остановке.

СОСТАВ
Включены исходные файлы, dist, worker, drizzle, тесты, документация,
site-edit (отдельная копия), прежние архивы, изображения и вспомогательные материалы.
Каталоги Git и node_modules вспомогательных инструментов исключены. Node.js и браузер в комплект не входят.
Ничего не опубликовано, удалённая база не изменялась.

ПРОВЕРКА СНИМКА

и архитектуры прошли. Далее ui-smoke-check.cjs остановился:
