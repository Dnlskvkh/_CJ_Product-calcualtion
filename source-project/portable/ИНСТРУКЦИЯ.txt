КАЛЬКУЛЯТОР ИЗДЕЛИЙ — ПЕРЕНОСНАЯ СБОРКА
Windows 10/11, 64-разрядная (x64). Нужен установленный Chrome или Edge.
Node.js включён в комплект. Установка и интернет для запуска не требуются.

ЗАПУСК
1. Распакуйте весь ZIP в обычную папку с правом записи, например Документы.
2. Дважды нажмите «Запустить калькулятор.cmd».
3. Калькулятор откроется в браузере: http://127.0.0.1:4189
   Если браузер не открылся, введите этот адрес вручную.
4. Держите окно запуска открытым. Остановка: Ctrl+C в нём или закрытие окна.
   Для следующего запуска используйте ту же команду и тот же браузер.
Не запускайте из самого ZIP. Права администратора не нужны.
Если порт занят, закройте предыдущее окно калькулятора и повторите запуск.

ГДЕ ДАННЫЕ
Сохранённые изделия, КП и справочники синхронизируются с локальной базой
data/calculator.sqlite в этой папке. Дождитесь статуса «Синхронизировано»
в разделе «Сервер и копии» перед остановкой. Это локальный сервер на вашем
компьютере, он не соединяется с базой опубликованного сайта.
Текущий несохранённый расчёт, часть черновиков и настройки остаются
в профиле браузера. Сохраните рабочий расчёт кнопкой «Сохранить JSON».
Не очищайте данные браузера без резервной копии.

ПЕРЕНОС ВАШИХ РАСЧЁТОВ
В ZIP нет ваших текущих данных браузера и базы опубликованного сайта.
1. На старом компьютере/сайте откройте «Сервер и копии» →
   «Скачать всю локальную базу». Дождитесь синхронизации с сайтом, если нужно.
2. Отдельно нажмите «Сохранить JSON» для нужного рабочего расчёта.
3. На новом компьютере запустите сборку. В «Сервер и копии» нажмите
   «Восстановить из файла» и выберите полный архив JSON.
4. Рабочую калькуляцию откройте кнопкой «Открыть» в шапке.
Перед импортом в непустую базу скачайте её копию. Импорт объединяет данные
по действующим правилам приложения: сверяйте результат объединения.

РЕЗЕРВНЫЕ КОПИИ И ОБНОВЛЕНИЯ
Регулярно скачивайте полную базу и отдельно нужные рабочие JSON.
Для переноса всей папки сначала дождитесь синхронизации и остановите сервер.
Копируйте папку целиком, включая data; черновики браузера переносите через JSON.
При обновлении не заменяйте свою папку data пустой папкой из нового ZIP.
Один адрес 127.0.0.1:4189 разделяет данные браузера между разными копиями
сборки на этом компьютере. Для независимой базы используйте отдельный
профиль браузера. Не запускайте несколько копий одновременно.
После обновления при старом интерфейсе нажмите «Обновить приложение» →
«Применить обновление» в калькуляторе.

КОМПЛЕКТ
app/worker.mjs — приложение со встроенными ресурсами, шрифтами и справочниками.
runtime/node.exe — среда запуска Node.js; лицензия: runtime/LICENSE.txt.
migrations — SQL-схема локального хранилища.
data — постоянная база, создаётся при первом запуске.
SHA256SUMS.txt — контрольные суммы исходных файлов сборки.
Сборка предназначена для внутренней работы сотрудников: содержит внутренние
справочники и ставки. Клиентам передавайте экспорт КП из приложения.
