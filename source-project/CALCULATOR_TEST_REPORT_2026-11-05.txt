ОБНАРУЖЕННАЯ ОШИБКА — P2

Взаимоисключающие работы из спецификации можно добавить двумя применениями.
Одновременный выбор двух работ одной alternative_group отклоняется правильно.
Если сначала применить первую работу, а затем ту же спецификацию со второй,
приложение оставляет в калькуляции обе. Это может завысить стоимость.

Причина: dist/model-spec-core.js:93–95 создаёт новый Set alternatives для
каждого вызова apply и проверяет только выбранные сейчас строки. Уже
добавленные строки сверяются лишь по точному modelSpecOrigin.rowKey.
Форма model-spec-ui.js использует это же ядро; отдельной проверки
ранее применённых альтернатив в форме нет.

Воспроизведение:
1. В валидной спецификации задать двум process_candidates одну alternative_group.
2. Добавить в пустую калькуляцию только первую работу.
3. Повторно применить эту же спецификацию, выбрав только вторую работу.
Ожидается блокировка конфликта с уже добавленной альтернативой.
Фактически добавляются обе работы.

Автоматическое воспроизведение:
node tests/scenarios/linked-product-scenarios.cjs --known-bug
Результат: 11 PASS, 1 FAIL, 83 проверки, код выхода 1.
Падающая проверка: Missing expected exception: Sequential application must
enforce the same alternative-group rule.
Контрольный совместный выбор двух альтернатив в этом же тесте отклонён.
Ошибка зафиксирована, прикладной код не исправлялся.
