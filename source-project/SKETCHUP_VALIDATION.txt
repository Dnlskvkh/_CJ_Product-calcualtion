ПРОВЕРКА РАСШИРЕНИЯ 0.2.0 · 10.11.2026

Пройдено:
— Подбор материала 0.2.0: собственные имена/определения/теги и теги родителей,
  приоритет собственных признаков, конфликты пород/марок, точное/неоднозначное
  название, отсутствие результата, переопределение поиском, указанные толщины,
  исключение архивов и позиций для сверки. «Лиственница» не распознаётся как
  «лист», отвод AISI 304 не предлагается вместо трубы AISI 304.
— Ruby SketchUp: сохранение названия определения и родительского тега в labels;
  чтение labels реальной открытой модели без изменения геометрии/выделения.
— Настоящий отдельный HtmlDialog 0.2.0: полный ui-check.js, точное предложение
  материала по названию компонента, перенос выбранного catalogId, сохранение
  закупочной единицы «лист», неизвестный расход м²→листы без явной нормы,
  пометка inference и происхождение подбора, сохранность явно снятого выбора.
  Рабочий state и черновик не изменены; тестовое окно закрыто после проверки.
— node run-checks.cjs: весь актуальный и регрессионный набор калькулятора,
  включая sketchup-check.cjs; формулы, архивы, схемы данных и клиентский whitelist.
— node build-sketchup.cjs: локальная сборка Worker/PWA и устанавливаемого RBZ.
— node sketchup-package-check.cjs: ресурсы страницы, автономный состав,
  встроенные TTF, SHA256 архива и побайтовое соответствие каждого файла ZIP
  исходному файлу сборки. Пользовательские базы и серверный API в RBZ не входят.
— SketchUp 26.1.189 / Ruby 3.2.2: geometry-check.rb на тестовых объектах
  и нативной математике Geom, без создания/удаления геометрии модели.
  Масштаб X/Y/Z, поворот, отражение родителя, масштаб вложенного узла,
  отдельные вхождения общей definition, скрытые объекты и папки тегов,
  неизвестный объём составного узла, исключение повторного счёта рёбер
  выбранной грани, масштаб выбранного ребра, стабильный снимок, сохранность
  идентификатора источника при смене GUID после сохранения SKP и пустой выбор.
— Чтение реальной открытой модели через Geometry.collect: получены 24 детали,
  у 23 доступен объём; число объектов, выделение и признак modified не изменились.
  Содержимое модели и названия деталей в отчёт не включены.
— Настоящий UI::HtmlDialog с собранной страницей: загрузка всех 21 проверяемого
  раздела, панели модели и локальных шрифтов; пустое выделение обрабатывается
  через реальный Ruby callback с понятным сообщением.
— ui-check.js в CEF: синтетическое выделение → карточки → выбор объёма →
  существующий помощник → чистое применение к отдельному тестовому расчёту.
  Проверены экранирование имён, м³, известный/null объём, null цены,
  защита повторного импорта, передача бинарного XLSX через FileReader/base64.
  Рабочий state и сохранённый черновик не изменены. Нативное сохранение
  в этом тесте заменено ответом, файл пользователя не записывался.
— Визуально просмотрены окно калькулятора и панель выбора геометрии в SketchUp.
  При ширине встроенного окна 700 px панель помещается, горизонтальной
  прокрутки документа нет; прежний размер окна восстановлен.
